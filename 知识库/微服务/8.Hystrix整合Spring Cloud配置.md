# 依赖引入

**概述：** Hystrix 通过 `spring-cloud-starter-netflix-hystrix` 引入。由于 Hystrix 已停更，需手动指定兼容版本（建议与 Spring Cloud 版本对齐）。

```xml
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-netflix-hystrix</artifactId>
    <version>2.2.10.RELEASE</version>
</dependency>
```

# application.yml 配置

**概述：** 在 Feign 配置中启用 Hystrix / CircuitBreaker 支持。

```yaml
feign:
  client:
    config:
      default:
        loggerLevel: FULL
  hystrix:
    enabled: true
  circuitbreaker:
    enabled: true
```

| 配置项 | 说明 |
|-------|------|
| `feign.hystrix.enabled` | 启用 Feign 的 Hystrix 降级支持 |
| `feign.circuitbreaker.enabled` | 启用 Spring Cloud CircuitBreaker 抽象层（推荐，兼容 Resilience4j） |
| `feign.client.config.default.loggerLevel` | Feign 日志级别，`FULL` 记录请求头、请求体和响应体 |

# 启动类配置

**概述：** 启动类添加 `@EnableHystrix` 注解开启 Hystrix 功能，同时需要 `@EnableFeignClients` 和 `@EnableDiscoveryClient`。

```java
@SpringBootApplication
@EnableDiscoveryClient
@EnableFeignClients
@EnableHystrix
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

# Feign 接口降级配置

**概述：** 在 `@FeignClient` 注解中通过 `fallback` 属性指定降级实现类。降级类实现 Feign 接口，重写每个方法返回兜底响应。

```java
@FeignClient(name = "demo-web", fallback = StudentHystrix.class)
@LoadBalancerClient(value = "demo-web", configuration = LoadBalancerConfig.class)
public interface StudentFeign {
    @RequestMapping("/student/test")
    Result test();

    @RequestMapping("/student/my")
    Result my();
}
```

```java
@Component
public class StudentHystrix implements StudentFeign {
    @Override
    public Result test() {
        return Result.fail("服务不可用");
    }

    @Override
    public Result my() {
        return Result.fail("系统错误");
    }
}
```

# FallbackFactory 配置（推荐）

**概述：** 使用 `FallbackFactory` 替代直接 `fallback`，可以获取触发降级的异常信息，便于日志排查。

```java
@Component
public class StudentFallbackFactory implements FallbackFactory<StudentFeign> {
    @Override
    public StudentFeign create(Throwable cause) {
        return new StudentFeign() {
            @Override
            public Result test() {
                log.error("test 服务降级，原因：{}", cause.getMessage());
                return Result.fail("服务不可用");
            }

            @Override
            public Result my() {
                log.error("my 服务降级，原因：{}", cause.getMessage());
                return Result.fail("系统错误");
            }
        };
    }
}
```

```java
// 使用 fallbackFactory 属性替代 fallback
@FeignClient(name = "demo-web", fallbackFactory = StudentFallbackFactory.class)
public interface StudentFeign { ... }
```

# 常用调优参数

**概述：** 以下是 Hystrix 常用的超时和熔断参数，可在 `application.yml` 中配置。

```yaml
hystrix:
  command:
    default:
      execution:
        isolation:
          thread:
            timeoutInMilliseconds: 3000   # 命令超时时间（默认1000ms）
      circuitBreaker:
        requestVolumeThreshold: 20        # 触发熔断的最小请求数（默认20）
        errorThresholdPercentage: 50      # 触发熔断的失败率阈值（默认50%）
        sleepWindowInMilliseconds: 5000   # 熔断后休眠窗口时间（默认5000ms）
```

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `timeoutInMilliseconds` | 1000 | 命令执行超时时间，超时触发降级 |
| `requestVolumeThreshold` | 20 | 滚动窗口内请求数达到此值才会触发熔断判定 |
| `errorThresholdPercentage` | 50 | 失败率百分比阈值，超过则打开熔断器 |
| `sleepWindowInMilliseconds` | 5000 | 熔断器打开后经过此时间进入半开状态 |

# 验证流程

1. 启动注册中心（Consul）、网关、服务提供者（至少 2 个实例）
2. 访问 Feign 客户端接口确认正常响应
3. 停止所有服务提供者实例
4. 再次访问 Feign 接口，确认返回降级响应（如 `"服务不可用"`）
5. 重启服务提供者，等待熔断器进入 Half-Open 状态后自动恢复

# 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 降级方法不生效 | 未启用 `feign.hystrix.enabled` 或缺少 `@EnableHystrix` | 检查配置和注解 |
| 超时频繁触发降级 | `timeoutInMilliseconds` 默认 1000ms 过短 | 适当调大超时时间 |
| Fallback 类未注入 | 降级类未添加 `@Component` | 确保降级类被 Spring 管理 |
| Feign + Hystrix 超时冲突 | Feign 和 Hystrix 各有超时设置 | Hystrix 超时 ≥ Feign 超时（含重试） |
