# Nacos Server 下载与安装

**概述：** Nacos Server 是独立运行的服务端进程，为所有微服务提供注册中心和配置中心能力。安装前需确保已安装 ==JDK 8+==（推荐 JDK 11），本文基于 Nacos 2.x 版本。

## 下载

**概述：** 从 GitHub Releases 页面下载对应操作系统的压缩包：

```
https://github.com/alibaba/nacos/releases
```

- Windows 选择 `nacos-server-x.x.x.zip`
- Linux/macOS 选择 `nacos-server-x.x.x.tar.gz`

**概述：** 下载后解压至无中文、无空格的路径（推荐放在系统盘根目录或固定目录下），目录结构如下：

```
nacos/
├── bin/          # 启动/停止脚本
├── conf/         # 配置文件
├── target/       # 运行 jar 包
└── logs/         # 日志目录
```

## 认证配置

**概述：** Nacos 2.x 默认关闭认证，生产环境 ==必须开启==。编辑 `conf/application.properties`，配置以下三项：

```properties
# 开启认证
nacos.core.auth.enabled=true

# Token 密钥（Base64 编码字符串，至少 32 字符原文）
# 生产环境必须替换为自定义密钥，切勿使用默认值
nacos.core.auth.plugin.nacos.token.secret.key=SecretKey012345678901234567890123456789012345678901234567890123456789

# 服务间认证标识（用于集群节点互相识别）
nacos.core.auth.server.identity.key=${NACOS_AUTH_IDENTITY_KEY:example}
nacos.core.auth.server.identity.value=${NACOS_AUTH_IDENTITY_VALUE:example}
```

> **注意：** `token.secret.key` 的默认值仅供开发测试，生产环境使用默认值会导致安全风险。建议使用 `openssl rand -base64 48` 生成随机密钥。

## 数据库配置（可选）

**概述：** Nacos 默认使用内嵌的 Derby 数据库，==不支持集群部署==。生产环境应切换到 MySQL（5.6.5+ 或 8.0+）。在 `conf/application.properties` 中配置：

```properties
spring.datasource.platform=mysql
db.num=1
db.url.0=jdbc:mysql://127.0.0.1:3306/nacos?characterEncoding=utf8&connectTimeout=1000&socketTimeout=3000&autoReconnect=true&useUnicode=true&useSSL=false&serverTimezone=UTC
db.user.0=root
db.password.0=your_password
```

**概述：** 配置前需先创建数据库并导入初始化脚本 `conf/mysql-schema.sql`。

## 启动与验证

**概述：** 进入 `bin/` 目录，执行启动命令。开发环境使用 ==standalone==（单机）模式：

```bash
# Windows
startup.cmd -m standalone

# Linux/macOS
sh startup.sh -m standalone
```

**概述：** 启动成功后控制台会输出 `Nacos started successfully in stand alone mode`。打开浏览器访问：

```
http://localhost:8848/nacos
```

- 默认用户名：`nacos`
- 默认密码：`nacos`

> **注意：** 生产环境应使用集群模式启动（不加 `-m standalone`），并配置 `conf/cluster.conf` 指定集群节点列表。

## 停止服务

```bash
# Windows
shutdown.cmd

# Linux/macOS
sh shutdown.sh
```

## 常见问题

**概述：** 安装过程中的典型问题及解决方案：

- **端口冲突** — Nacos 默认占用 8848（主端口）、9848（gRPC 客户端）、9849（gRPC 服务端）。若端口被占用，在 `application.properties` 中修改 `server.port`
- **启动闪退** — 检查 `JAVA_HOME` 是否正确配置，查看 `logs/start.out` 获取详细错误信息
- **内存不足** — 默认 JVM 参数为 `-Xms512m -Xmx512m`，可在 `startup.cmd/sh` 中调整
