# 安装 IK 分词器

**概述：** IK 分词器是 ES 最常用的中文分词插件，==版本号必须与 ES 版本完全一致==。安装前需要停止 ES 和 Kibana 服务。

```bash
# 切换到 root 用户
# 进入 ES 插件目录
cd /opt/elasticsearch-7.6.2/plugins

# 创建插件目录
mkdir ik && cd ik

# 上传 zip 包后解压（需先安装 unzip）
yum install -y unzip zip
unzip elasticsearch-analysis-ik-7.6.2.zip
```

**概述：** 安装完成后重启 ES，启动日志中出现 `loaded plugin [analysis-ik]` 即表示加载成功。

# 分词策略

**概述：** IK 提供两种分词模式，适用于不同场景。可通过 `_analyze` API 测试分词效果。

| 模式 | 算法 | 适用场景 |
|------|------|---------|
| `ik_smart` | ==最粗粒度==，优先最长匹配 | 搜索关键词分词（减少噪音） |
| `ik_max_word` | ==最细粒度==，穷举所有组合 | 索引内容分词（提高召回率） |

测试分词效果：

```json
// ik_smart 模式
POST /_analyze
{
  "analyzer": "ik_smart",
  "text": "中华人民共和国国歌"
}

// ik_max_word 模式
POST /_analyze
{
  "analyzer": "ik_max_word",
  "text": "中华人民共和国国歌"
}
```

# 自定义词典

**概述：** IK 内置词库无法覆盖所有词汇（如网络用语、专业术语）。通过自定义扩展词典和停用词词典可解决。配置文件位于 `plugins/ik/config/IKAnalyzer.cfg.xml`。

## 创建扩展词典

创建 `.dic` 词典文件，每行一个词：

```
# 文件名：custom_ext.dic
吊炸天
奥利给
内卷
```

## 创建停用词典

```
# 文件名：custom_stop.dic
的
了
啊
```

## 修改配置文件

```bash
vi /opt/elasticsearch-7.6.2/plugins/ik/config/IKAnalyzer.cfg.xml
```

==注意==：配置文件中不要保留中文注释，否则可能导致编码问题。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE properties SYSTEM "http://java.sun.com/dtd/properties.dtd">
<properties>
    <entry key="ext_dict">custom_ext.dic</entry>
    <entry key="ext_stopwords">custom_stop.dic</entry>
</properties>
```

**概述：** 修改完成后将词典文件和配置文件上传到 `plugins/ik/config/` 目录，重启 ES 和 Kibana 生效。IK 还支持配置==远程词典==（通过 HTTP URL），实现热更新词库而无需重启。

```mermaid
flowchart LR
    A[编写 .dic 词典文件] --> B[修改 IKAnalyzer.cfg.xml]
    B --> C[上传到 plugins/ik/config/]
    C --> D[重启 ES]
    D --> E[通过 _analyze 验证]
```
